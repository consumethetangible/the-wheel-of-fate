How it works

Three of us, two picks each: one beloved album and one we want to explore. Group by switches the list between pick type and person.

  1. Add your picks. Type an artist and album into a seat. The cover and official names come from Apple Music, with MusicBrainz as a backup.
  2. Fix a missing or wrong cover. Tap a seat's cover, or Find cover, to choose from the matches. You can also paste an Apple Music, YouTube or Bandcamp link, or an image address.
  3. Seal each seat. Sealing locks the pick in. Edit unlocks it again to fix a typo.
  4. Spin. When all six are sealed, the wheel is ready. Each album's slice is sized by its weight.
  5. Weight is automatic. Every album starts at 1× and gains 1 for each spin it sits through. Replace it and it starts over at 1×.
  6. After a result. Accept it and the winner leaves, which opens its seat. Add the new pick any time before the next spin. You can replace any other seat whenever you like.
  7. Every result gets a story, told in a different voice each round. Another telling swaps in a new one. History keeps every winner: open an entry to read its story, retell it, edit it, fix the cover, or save it as an image.

Connect to GitHub

The wheel saves to a file in your repo as you work, so every change is backed up and can be rolled back. Paste the access token once on each device.

Repository details

How to make the access token
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Choose Generate new token and name it something like Wheel of Fates. Set an expiry you are comfortable with.
  3. Under Repository access, choose Only select repositories and pick the-wheel-of-fate.
  4. Under Permissions, Repository permissions, set Contents to Read and write.
  5. Generate the token, copy it, and paste it above. GitHub only shows it once.
The token stays in this browser only, and it can touch that one repo and nothing else.

Where do I find a link?
  • Apple Music. Right-click the album, Share, Copy Link. This always works, even for albums search cannot find.
  • YouTube. Paste a link to a video from the album. If the video shows the album cover, that is what you get.
  • Bandcamp. Paste the album page link. If that fails, right-click the cover, choose Copy Image Address, and paste that instead.
  • Anything else. A link to the picture itself also works.
